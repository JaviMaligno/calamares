# Reducción uniforme del umbral

**Estado:** reducción adyacente escrita y tres certificados Lean
compilados. README y hoja de generalizaciones pasan al objetivo uniforme.
El lema geométrico de intercambio sigue abierto; no se marca resuelto
tau=phi. La nueva nota no se ha enviado a revisión externa.

**Goal:** sustituir la clasificación por número de aros por un enunciado
de intercambio válido para cualquier inventario finito, con una obstrucción
residual explícita y sin afirmar el cierre global.

**Architecture:** usar las dos desigualdades consecutivas de cola para
evacuar todos los menores salvo el primero. Combinar los certificados de
un testigo P y del prefijo voraz F para reducir un intercambio bloqueado
a dos aros consecutivos que permutan contenedores. Mantener separados
los criterios geométricos C1/C2, el caso general pendiente y su soporte Lean.

**Tech Stack:** prueba escrita, Lean 4.32.2 core, aritmética racional exacta.

**Risks:** extrapolar casos de tamaño acotado; confundir una condición
necesaria de bloqueo con una refutación; usar solo álgebra cuando hacen
falta bolsillos euclidianos; alterar fuentes congeladas de v2.

## Criterio de avance

La reducción debe cuantificar sobre todo n finito y todo grado de los
contenedores. Una nueva cota para un n fijo no cuenta como cierre de
este objetivo. El umbral global queda abierto mientras no se demuestre
el intercambio geométrico residual o se construya un contraejemplo.
